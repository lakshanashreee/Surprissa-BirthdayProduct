# Happy Birthday Stacy! 🎂✨

A personalized, interactive digital birthday celebration website created especially for Stacy.

## Features Included
- **Suspicious Russian Doll Box**: Hilarious interactive nested gift boxes leading to the celebration.
- **Catch 10 Hearts for Stacy**: Interactive floating heart collection game.
- **Chaotic Cake Candles**: Blow out candles with dodge mechanics and blackout surprise.
- **Birthday Vibe Check**: Runaway "NO" button interaction and universal truths verification.
- **Photo Museum**: Curated memory polaroids with rotating frames, sticker notes, and falling hearts.
- **Audio Voice Note**: Personalized voice memo player with audio visualizer.
- **Confidential Letter**: Passcode protected vault that unseals with raining hearts.
- **Sound System**: Real-time synthesized web audio effects and interactive sound toggle.

## Running Locally
```bash
npm install
npm run dev
```
